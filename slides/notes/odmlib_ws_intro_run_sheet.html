4/16
What is Define-XML?
Calibrate to the room - many know define.xml as "that XML file". The key reframe: it is not a document, it is a graph of cross-referenced metadata. That is why generic XML tooling falls short and why dedicated tooling matters.
5/16
What is odmlib?
Positioning: this is not an XML helper - it is a model of the standard itself. Namespaces, element order, and required attributes live in the model, not in your code. The snippet is real - students write this in Block 1.
6/16
One library, the whole ODM family
Today is Define-XML-focused, but Block 1's stretch goal loads an ARM define with a two-line change. Dataset-JSON support connects directly to last year's R/Pharma Dataset-JSON workshop.
7/16
Why not hand-roll the XML?
Key line: hand-rolling Define-XML is how subtle, expensive errors get made - odmlib makes the correct way the easy way. Note the typo in both snippets: ElementTree ships it silently; odmlib's OID checker names it.
